# v6 → v7 change map

Baseline: `KAGGLE-27-protocol-v6-and-verifier.zip`, SHA256 `826453e89d044fa27139138fa5dc6fd1a938e8e6944730644802e50b1fa882d9`.

| Review finding | v6 behavior | v7 change | Evidence |
|---|---|---|---|
| B1 trust root and scope | A file outside the data root could be treated as a trust registry; gate/object/version/subject scope was not enforced. | Require scope entries to bind all four gates, the exact object binding list and purposes, fixed E0 commit, subject OS identity, operation, and a nonexpired timestamp. Production also hard-blocks because no deployment-controlled provider is installed. | `neg_b1_approval_scope_forgery` → `EVIDENCE_APPROVAL_SCOPE_MISMATCH`, `REAL_TRUST_PROVIDER_UNAVAILABLE`, `AUTH_BEFORE_ACCESS`; 0 protected opens, 0 consumers. |
| B2 object authorization SHA | Grants were checked by path; candidate and denylist grants were not compared with the measured bytes. | Compare candidate, denylist, snapshot, evidence, and closure grants to the SHA of the same read buffer; purpose is checked separately. Any mismatch blocks consumers. | `neg_b2_grant_sha_mismatch` → `AUTH_OBJECT_HASH_MISMATCH`, 0 consumers. |
| B2 transitive dependencies | Closure scanning opened all Python files before reporting an omitted `faces.py` grant. | Traverse import buffers one at a time. Check the exact path grant before each open; a missing child dependency is recorded without opening that path. | `neg_b2_unauthorized_dependency_zero_open` → `AUTH_SCOPE_INSUFFICIENT`, unauthorized opens 0, consumers 0. |
| B4 receipt mutation | Expected receipt digest was reread from the path after the child process exited. | Save expected digests from the pre-run input snapshot and compare the child's receipt to those saved values. | `neg_b4_receipt_mutation_uses_pre_run_digest` mutates candidate and returns its new digest; v7 reports `INPUT_BYTES_MISMATCH`. |
| B4 E0 package initialization | Required subpackage `__init__.py` files were missing from the fixed closure; snapshot imports could change package semantics. | Add parent initializers and E0 `REQUIRED_EXECUTION_PATHS` to the bound closure. Before real CLI runs, a child probe checks `v3` and its fixed subpackage origins against the snapshot paths. | `neg_b4_required_package_init_missing`; `package_origin_probe` in real-CLI cases. |
| Git blob identity | A working-tree SHA-1 could be labeled as the fixed commit's blob identity; CRLF checkout bytes were conflated with Git object bytes. | Query `git rev-parse <fixed-commit>:<path>` and `git cat-file blob` for the fixed E0 commit; compare worktree bytes as either identical or explicit CRLF→LF mapping. Synthetic fixtures use `git_source=not_git` and null blob/commit fields. | `neg_git_blob_zero_placeholder`; generator checks the mutation digest changed. |
| Y1 open audit cap | Audit stream silently stopped at 20,000 events. | Set an overflow flag and emit `AUDIT_LOG_OVERFLOW`; overflow cannot support zero-open evidence or acceptance. | `neg_y_audit_log_overflow` opens 20,005 times; `AUDIT_LOG_OVERFLOW`, consumers 0. |
| Version-sensitive cases | CLI mutation could replace a stale string without changing the source; legacy schema control followed the current E0 tree. | Mutation appends a marker and asserts source SHA changed. The older negative control is materialized from pinned `ffc37b4f3ecde6579117b0012ab4f69b4cff16ab`; v7 E0 is pinned to `128d9b98b05ddf128c2e77b599e078de65675b8a`. | `e0_mutation_record.json`; `neg_b4_old_e0_schema_unconsumed`. |

The original v6 ZIP is unchanged. Its checker, protocol, template, P5 cases, and fixtures are also retained under `preserved/protocol-v6/` for byte-level comparison.
